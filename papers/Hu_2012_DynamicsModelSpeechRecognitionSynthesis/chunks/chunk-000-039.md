## Key Findings

- **Central thesis**: Non-linear formant trajectories can model speech dynamics better than piecewise linear trajectories in the MSHMM framework
- **12 PFS (Parallel Formant Synthesiser) control parameters**: The intermediate "articulatory" layer uses Holmes-Mattingly-Shearme (HMS) formant synthesizer parameters
- **Tokuda's SPG algorithm** (1995): Generates smooth, non-linear trajectories that vary within state occupancy and are affected by neighbouring states - adopted for formant dynamics
- **Trajectory HMM** (Tokuda 2003): Reformulated standard HMM where mean trajectory is consistent with static and dynamic constraints (not piecewise constant)
- **Linear MSHMM achieves upper bound performance**: Phone classification with formant-based intermediate layer does not compromise system performance vs. conventional HMMs
- **25% fewer parameters**: MSHMM with intermediate layer achieves superior performance with 25% fewer parameters than conventional HMM
- **Formant dynamics correlate with articulator dynamics**: F1 correlates with tongue height (closer tongue = lower F1), F2/F3 reflect tongue position/shape
- **F1 example**: /i/ in "beet" has F1 ~300 Hz, /o/ in "bought" has F1 ~950 Hz
- **Coarticulation effects**: Nasalized [ae] in "cant" shows velar lowering spreading from following nasal [n]
- **Piecewise linear trajectory limitations**: No continuity constraints across segment boundaries, cannot model long-span dependencies

## Equations Found

### Gaussian Mixture Model Output (Eq. 2.1)
$$b_i(\mathbf{o}_t) = \sum_{k=1}^{K} w_{ik} \mathcal{N}(\mathbf{o}_t | \boldsymbol{\mu}_{ik}, \boldsymbol{\Sigma}_{ik})$$

Where:
- $b_i(\mathbf{o}_t)$ = output probability density in state $i$ at time $t$
- $w_{ik}$ = weight of $k$-th mixture component in state $i$ (sum to 1)
- $\boldsymbol{\mu}_{ik}$ = mean vector of mixture component
- $\boldsymbol{\Sigma}_{ik}$ = covariance matrix (typically diagonal)

### Dynamic Features / Delta Coefficients (Eq. 2.2)
$$\Delta \mathbf{c}_t = \frac{\sum_{\theta=1}^{\Theta} \theta(\mathbf{c}_{t+\theta} - \mathbf{c}_{t-\theta})}{2\sum_{\theta=1}^{\Theta} \theta^2}$$

Where:
- $\mathbf{c}_t$ = static feature vector at time $t$
- $\Delta \mathbf{c}_t$ = delta (velocity) coefficient
- $\Theta$ = typically 2, giving window of 4+8 frames for delta and acceleration

### SHMM Segment Output Distribution (Eq. 2.3)
$$p(\mathbf{o}_1^l, l | s_i) = p(\mathbf{o}_1^l | l, s_i) p(l | s_i) = b_i(\mathbf{o}_1^l) d_i(l)$$

Where:
- $\mathbf{o}_1^l$ = observation sequence of length $l$
- $s_i$ = state $i$
- $b_i$ = segmental output distribution
- $d_i(l)$ = explicit state duration distribution

### SHMM with IID Observations (Eq. 2.4)
$$p(\mathbf{o}_1^l, l | s_i) = b_i(\mathbf{o}_1^l) d_i(l) = d_i(l) \prod_{t=1}^{l} p(\mathbf{o}_t | s_i)$$

### Static Gaussian SHMM Joint Probability (Eq. 2.5)
$$p(\mathbf{o}_1^l, \mathbf{c} | s_i) = d_i(l) b_i(\mathbf{c}) p(\mathbf{o}_1^l | \mathbf{c}) = d_i(l) \mathcal{N}(\mathbf{c} | \boldsymbol{\nu}_i, \boldsymbol{\eta}_i) \prod_{t=1}^{l} \mathcal{N}(\mathbf{o}_t | \mathbf{c}, \boldsymbol{\Sigma}_i)$$

Where:
- $\mathbf{c}$ = target vector (constant throughout segment)
- $\boldsymbol{\nu}_i, \boldsymbol{\eta}_i$ = extra-segmental mean and variance (speaker identity, etc.)
- $\boldsymbol{\Sigma}_i$ = intra-segment variance

## Rules/Algorithms

### Multiple-Level Segmental HMM (MSHMM) Architecture
1. **Acoustic layer**: MFCCs or other spectral features
2. **Synthetic acoustic layer**: Transformed from intermediate layer
3. **Formant-to-acoustic mapping**: Linear (W) or non-linear projection
4. **Formant-based intermediate layer**: 12 PFS control parameters with trajectories
5. **Finite state process**: Phoneme/state sequence

### HMM Generative Process
1. At time t=1, determine initial state i from probability vector pi
2. Generate observation o_t according to state output PDF b_i
3. Transition to state j according to transition matrix A
4. Repeat until sequence complete

### Three Key HMM Assumptions (Holmes & Russell 1999)
1. **Piecewise stationarity**: Acoustic observations from stationary regions with instantaneous transitions
2. **Independence assumption**: Consecutive frames are IID given state (a.k.a. "independence assumption")
3. **First-order Markov**: State sequence is first-order Markov chain with geometric duration model

### SHMM Generation Mechanism
1. At time t, stochastic process enters state s_i
2. Stay in state for period l determined by duration distribution d_i
3. Generate single sample from segmental output distribution b_i
4. Transition to new state according to transition matrix
5. Repeat

## Implementation Notes

### For Klatt Synthesis Relevance

1. **12 PFS Control Parameters**: The thesis uses Holmes-Mattingly-Shearme synthesizer parameters as the intermediate representation. These map to Klatt parameters:
   - First three formant frequencies (F1, F2, F3)
   - Corresponding bandwidths
   - Source parameters

2. **Non-linear trajectory generation** is the key contribution - rather than stepping between phoneme targets, formant trajectories should be:
   - Smooth and continuous across segment boundaries
   - Affected by neighbouring segments (coarticulation)
   - Non-linear within segments

3. **Formant-to-acoustic mapping** can be:
   - Linear: Simple matrix multiplication W
   - Non-linear: MLP or RBF networks (10% better RMS error than MLP)

4. **Dynamic features**: Delta and delta-delta coefficients computed from surrounding frames capture velocity and acceleration of formant movement

### Data Structures
- **Observation sequence**: $\mathbf{o}_1^T = \{\mathbf{o}_1, \ldots, \mathbf{o}_T\}$
- **State sequence**: $\mathcal{S} = \{s_1, \ldots, s_N\}$
- **Segment**: Sequence of observations $\mathbf{o}_1^l$ of length $l$ in state $s_i$
- **Trajectory**: Time-varying parameter values through segment

### Processing Pipeline
1. Text input
2. Phone sequence generation
3. State sequence with durations
4. Formant trajectory generation (SPG algorithm)
5. Formant-to-acoustic mapping
6. Waveform synthesis
