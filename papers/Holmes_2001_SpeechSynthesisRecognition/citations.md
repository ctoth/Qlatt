## Key Citations for Follow-up

1. **Holmes, Mattingly & Shearme 1964** — Original HMS synthesis-by-rule paper with complete table specifications. Essential for understanding the table-driven approach described in Chapter 6.

2. **Holmes 1983** — "Formant synthesizers: cascade or parallel?" Detailed comparison and description of the parallel formant synthesizer shown in Figure 2.15.

3. **Klatt 1980** — "Software for a cascade/parallel formant synthesizer" — the primary reference for Qlatt's synthesizer architecture.

4. **Allen, Hunnicutt & Klatt 1987** — "From Text to Speech: the MITalk System" — the most complete description of a formant-synthesis TTS system.

5. **Pierrehumbert 1980/1981** — Tone-sequence model for F0 contour generation, basis for TOBI; directly relevant to Qlatt's prosody rules.
