Proposes a three-level model relating phonological [+/-voice] features to phonetic implementation through an intermediate level of universal phonetic categories ({voiced}, {vl.unasp.}, {vl.asp.}), using VOT data from Polish, English, and German. Demonstrates that cross-language differences in stop consonant voicing are best described as different mappings from the same binary phonological feature to the same set of phonetic categories, with language-specific quantitative detail rules providing exact parameter values. Provides extensive VOT distribution data and discusses implications for vowel duration, F0 perturbation, neutralization, and markedness.
