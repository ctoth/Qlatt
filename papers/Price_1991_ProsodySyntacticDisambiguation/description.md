Systematic study of how prosodic cues (phrasing, duration, pausing, boundary tones, prominence) disambiguate seven types of syntactic structural ambiguity using 35 sentence pairs read by professional FM radio announcers. Introduces a 7-level prosodic break index system (precursor to ToBI) and shows that clause boundaries reliably correspond to major prosodic boundaries while within-clause syntactic boundaries map to smaller breaks with more speaker variation. Provides quantitative perceptual data on listener disambiguation accuracy (84% average) and phonological analysis of the prosodic correlates of each structural type.
