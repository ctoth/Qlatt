This paper presents the foundational framework of articulatory phonology, in which gestures -- abstract characterizations of articulatory events with intrinsic duration -- replace segments and features as the basic units of phonological contrast, with utterances modeled as temporally overlapping gestural constellations organized across vocal tract variable tiers. The key contribution is demonstrating that coarticulation, allophonic variation (aspirated/unaspirated stops, clear/dark /l/), assimilation, consonant deletion, and fluent speech alternations all follow automatically from patterns of gestural overlap and reduction, without requiring separate phonological rules or categorical feature changes. For speech synthesis, this framework provides theoretical grounding for implementing coarticulation as gestural blending, position-dependent allophony as gradient timing variation, and speaking-rate effects as overlap modulation, directly informing the formant transition rules and duration models used in Klatt-based TTS systems like Qlatt.
