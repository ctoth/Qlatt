## Key Findings

- **Linear trajectory models** characterize observations within a segment using a "noisy" linear trajectory instead of constant trajectory (static SHMM)
- **Linear trajectory equation**: $\boldsymbol{f}(t) = (t - \bar{t})\boldsymbol{m} + \boldsymbol{c}$ where $\bar{t} = (l+1)/2$ is the midpoint of segment
- **PTSHMM family tree** shows relationships between models:
  - Static SHMM: slope mean $\mu=0$, slope variance $\gamma=0$
  - FT-SHMM: slope variance $\gamma=0$, mid-point variance $\eta=0$
  - HSMM: slope $m=0$
  - Standard HMM: duration = geometric
- **Linear PTSHMMs** outperform both static PTSHMMs and linear FTSHMMs (26.8% error vs 27.4% and 29.4% respectively)
- **Trajectory-independent probability calculation** outperforms most-likely-trajectory by 75.6%, 71%, and 60% reduction in WER
- **Non-parametric models** use mean trajectories (templates) instead of polynomial functions; suitable for phones with discontinuities (stops)
- **Linear Dynamical Systems (LDS)** model state evolution: $\boldsymbol{x}_t = \boldsymbol{F}\boldsymbol{x}_{t-1} + \boldsymbol{w}_t$
- **Hidden Dynamic Models (HDMs)** incorporate articulatory intermediate layer between symbolic and acoustic representations
- **HDMs demonstrated 32% reduction in WER** when reference transcriptions included in N-best list
- **Feature-based HMMs** outperform phonemic CI HMMs by 27% in error rate
- **Vocal tract resonances (VTRs)** provide appropriate hidden representation since they're closely related to both articulation and acoustics
- **10% change in formant frequencies** makes dramatic perceptual change (primarily speaker characteristics)
- **F1** correlates with tongue height (lower F1 = closer to roof of mouth)
- **F2** proportional to frontness/backness of tongue highest part
- **Formant frequencies above F3** have little perceptual effect
- **Formant trajectories vary smoothly** due to vocal tract constraints, unlike erratic MFCC variations
- **12 PFS parameters** used as synthesis control: F1-F3 frequencies/amplitudes, F0, low-frequency amplitude, high-frequency amplitude, voicing degree, glottal pulse mark-space ratio
- **HMS formant synthesizer** uses parallel resonator architecture with three formants plus high-frequency resonator

## Equations Found

### Linear Trajectory Model
$$\boldsymbol{f}(t) = (t - \bar{t})\boldsymbol{m} + \boldsymbol{c}$$
Where:
- $\bar{t} = (l+1)/2$ is midpoint of segment
- $\boldsymbol{m}$ is slope vector
- $\boldsymbol{c}$ is mid-point vector (target)
- $t$ is frame index within segment

### Slope and Mid-point Estimation (Least Squares)
$$\boldsymbol{m}' = \frac{\sum_{t=1}^{l}(t-\bar{t})\boldsymbol{o}_t}{\sum_{t=1}^{l}(t-\bar{t})^2}, \quad \boldsymbol{c}' = \frac{\sum_{t=1}^{l}\boldsymbol{o}_t}{l}$$
Where: $\boldsymbol{o}_t$ are observations, $l$ is segment length

### Optimal Target (GSHMM)
$$\hat{\boldsymbol{c}} = \frac{\boldsymbol{\nu}_i\boldsymbol{\Sigma}_i + \sum_{t=1}^{l}\boldsymbol{o}_t\boldsymbol{\eta}_i}{\boldsymbol{\Sigma}_i + l\boldsymbol{\eta}_i}$$
Where:
- $\boldsymbol{\nu}_i$ is prior mean
- $\boldsymbol{\eta}_i$ is prior covariance
- $\boldsymbol{\Sigma}_i$ is intra-segment covariance

### Most-Likely Trajectory Estimates
$$\hat{\boldsymbol{m}} = \frac{\left(\sum_{t=1}^{l}(t-\bar{t})\boldsymbol{o}_t\right)\boldsymbol{\gamma}_i + \boldsymbol{\mu}_i\boldsymbol{\Sigma}_i}{\left(\sum_{t=1}^{l}(t-\bar{t})^2\right)\boldsymbol{\gamma}_i + \boldsymbol{\Sigma}_i}$$
$$\hat{\boldsymbol{c}} = \frac{\left(\sum_{t=1}^{l}\boldsymbol{o}_t\right)\boldsymbol{\eta}_i + \boldsymbol{\nu}_i\boldsymbol{\Sigma}_i}{l\boldsymbol{\eta}_i + \boldsymbol{\Sigma}_i}$$

### Polynomial Trajectory Segment Model
$$\boldsymbol{C} = \boldsymbol{Z}\boldsymbol{B} + \boldsymbol{E}$$
Where:
- $\boldsymbol{C}$ is $N \times D$ data matrix (speech segment)
- $\boldsymbol{Z}$ is $N \times R$ design matrix (time normalization)
- $\boldsymbol{B}$ is $R \times D$ trajectory parameter matrix
- $\boldsymbol{E}$ is residual error matrix
- $R=1$ for constant, $R=2$ for linear, $R=3$ for quadratic

### Design Matrix for Quadratic Trajectory
$$\boldsymbol{Z} = \begin{bmatrix} 1 & -\frac{M}{2M} & (-\frac{M}{2M})^2 \\ 1 & -\frac{M-1}{2M} & (-\frac{M-1}{2M})^2 \\ \vdots & \vdots & \vdots \\ 1 & 0 & 0 \\ \vdots & \vdots & \vdots \\ 1 & \frac{M}{2M} & (\frac{M}{2M})^2 \end{bmatrix}$$

### Trajectory Parameter Estimation (Least Squares)
$$\hat{\boldsymbol{B}}_k = [\boldsymbol{Z}_k^\top \boldsymbol{Z}_k]^{-1}\boldsymbol{Z}_k^\top \boldsymbol{C}_k$$

### Residual Error Covariance
$$\hat{\boldsymbol{\Sigma}}_k = \frac{\hat{\boldsymbol{E}}_k^\top \hat{\boldsymbol{E}}_k}{N_k} = \frac{(\boldsymbol{C}_k - \boldsymbol{Z}_k\hat{\boldsymbol{B}}_k)^\top(\boldsymbol{C}_k - \boldsymbol{Z}_k\hat{\boldsymbol{B}}_k)}{N_k}$$

### Linear Dynamical System State Equations
$$\boldsymbol{x}_t = \boldsymbol{F}\boldsymbol{x}_{t-1} + \boldsymbol{w}_t$$
$$\boldsymbol{o}_t = \boldsymbol{H}\boldsymbol{x}_t + \boldsymbol{v}_t$$
Where:
- $\boldsymbol{x}_t$ is $m$-dimensional unobserved state vector
- $\boldsymbol{o}_t$ is $n$-dimensional observation vector
- $\boldsymbol{F}$ is $m \times m$ state evolution matrix
- $\boldsymbol{H}$ is $n \times m$ observation matrix
- $\boldsymbol{w}_t \sim \mathcal{N}(\boldsymbol{\mu}^{(x)}, \boldsymbol{\Sigma}^{(x)})$ is state noise
- $\boldsymbol{v}_t \sim \mathcal{N}(\boldsymbol{\mu}^{(o)}, \boldsymbol{\Sigma}^{(o)})$ is observation noise

### General State-Space Model
$$\boldsymbol{x}_t = f(\boldsymbol{x}_{t-1}, \ldots, \boldsymbol{x}_1, \boldsymbol{w}_t)$$
$$\boldsymbol{o}_t = h(\boldsymbol{x}_t, \boldsymbol{v}_t)$$

### Template Selection (Non-parametric)
$$\sum_{k=1}^{K} D(\bar{\boldsymbol{O}}, \boldsymbol{O}_k) \leqslant \sum_{k=1}^{K} D(\boldsymbol{O}_j, \boldsymbol{O}_k)$$
Where: $D(\cdot,\cdot)$ is DTW distance between observation sequences

### Gauss-Markov Segment Probability
$$b_i(\boldsymbol{o}_1^l) = \prod_{t=1}^{l} p(\boldsymbol{o}_t | \boldsymbol{o}_{t-1}, s_i)$$

### Hamming Window Function
$$s'_n = \left\{0.54 - 0.46\cos\left(\frac{2\pi(n-1)}{N-1}\right)\right\}s_n$$

### Mel-Frequency Conversion
$$\text{Mel}(f) = 2595\log_{10}(1 + \frac{f}{700})$$

### MFCC Calculation (DCT)
$$c_i = \sqrt{\frac{2}{M}}\sum_{j=1}^{M} m_j\cos\left(\frac{\pi i}{M}(j - 0.5)\right)$$
Where: $m_j$ are mel-scale filter bank amplitudes

## Rules/Algorithms

### Holmes Formant Analysis Pipeline (Section 3.2.3)
1. Sample speech at 8,000 Hz (4 kHz bandwidth)
2. Apply pitch-synchronous Fourier analysis to generate 31-dimensional log power spectral vector every 10ms (frequencies 125-3875 Hz)
3. Compare input spectrum to codebook of 150 reference spectra using Euclidean distance
4. Select shortlist of 6 best-matching reference spectra
5. Apply dynamic programming (DP) frequency warping to find best match
6. Adjust formant frequencies according to frequency warping results
7. Apply parabolic interpolation for fine frequency adjustment
8. Apply DP time smoothing to select formant trajectories with minimum discontinuity
9. Determine formant amplitudes from input cross-section amplitudes at estimated formant frequencies
10. Output formant frequencies and amplitudes every 10ms

### JSRU Formant Synthesis Pipeline (Section 3.2.4)
1. **Text-to-phone conversion**: Convert orthographic text to phonetic elements
   - Some phonemes represented by two vowel-like elements (diphthongs)
   - Stops treated as three elements: closure, high-energy release, diminished release
2. **Synthesis-by-rule**: Generate synthesizer control parameters from phonetic elements
   - Use talker table for target frequencies/amplitudes
   - Apply linear interpolation for smooth formant transitions
   - Calculate boundary values from fixed contribution + proportion of adjacent target
3. **Parallel formant synthesizer**: Generate speech from control parameters
   - Three parallel resonators for F1, F2, F3
   - Fourth resonator for high-frequency energy
   - Voiced/unvoiced excitation controlled by V parameter
   - Parameters updated every 10ms

### Formant Transition Interpolation Rule
For [w] to [e] transition with:
- [w] target F2 = 750 Hz
- [e] target F2 = 2000 Hz
- Fixed contribution to boundary = 350 Hz
- Proportion of adjacent target = 0.5
- Internal duration (ID) = 40ms
- External duration (ED) = 100ms

Boundary value: $F_2^b = 350 + 0.5 \times 2000 = 1350$ Hz

## Implementation Notes

### Formant-Based Hidden Representation
- First three formant frequencies (F1, F2, F3) form a 3-dimensional hidden space
- Formants are closely related to both articulation AND acoustics
- For non-nasalized vowels, VTRs coincide exactly with formants
- For consonants, formants are hidden or perturbed by spectral zeros and turbulence

### Design Matrix Construction
For a segment of length $N = 2M + 1$ frames with quadratic trajectory ($R=3$):
- Normalize time to range [-0.5, 0.5]
- First column: all 1s (constant term)
- Second column: normalized time (linear term)
- Third column: normalized time squared (quadratic term)

### Critically-Damped Low-Pass Filter for Hidden Dynamics
The causal second-order critically-damped low-pass filter state equation:
$$x(t) = 2\rho x(t-1) - \rho^2 x(t-2) + (1-\rho)^2 c + w(t)$$
Where:
- $\rho$ determines rate of approach to target $c$
- Global smoothness achieved by continuity constraints at phone boundaries

### Hidden-Trajectory HMM (HTHMM)
Combines advantages of HDMs and HMMs:
- Same state equation as causal low-pass filter
- Frame-wise noise term removed for simple training
- Hidden trajectory incorporated into standard HMM with Gaussian mixture output
- Achieved slightly better performance than triphone HMMs with 20% fewer parameters

### Parallel Formant Synthesizer Architecture
1. Three resonators in parallel for F1, F2, F3
2. Fourth resonator for high-frequency energy (centered ~3500 Hz)
3. Separate mixing of voiced and unvoiced excitation for each formant
4. Control parameters sent every 10ms
5. Voicing control parameter V determines excitation mix:
   - V = 1: completely unvoiced (noise source)
   - V = 63: fully voiced (periodic waveform with F0)

### Key Implementation Considerations
- PFS parameters vary slowly and smoothly (unlike MFCCs)
- Linear trajectories sufficient for most sounds; quadratic needed only for diphthongs
- Non-parametric models better for stops (discontinuous at closure/burst)
- Formant estimation difficult for unvoiced sounds and nasals (spectral zeros)
- Holmes analyser uses 150 reference spectra codebook for formant matching
- DP time smoothing ensures formant trajectory continuity across frames
