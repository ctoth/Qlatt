# Description

Rothenberg et al. (1975) present an analog circuit-based "black box" model of the glottal voice source controlled by three physiologically motivated parameters: F (fundamental frequency), L (loudness/subglottal pressure), and T (tightness/glottal adduction-abduction). The model uses an RC lowpass filter with diode-based clipping to produce glottal-like waveforms whose shape varies naturally with the three control parameters, including coupled changes in spectral tilt, amplitude, and pulse width. The paper demonstrates integration with the OVE III formant synthesizer at KTH, showing how the three-parameter control simplifies rule-based synthesis of glottal transitions, aspiration, boundary marking via glottal stops, and allophonic variation in [h].
