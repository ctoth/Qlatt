## Key Findings

### Formant Trajectory Smoothing
- Non-linear formant trajectories (generated by SPG algorithm) provide smoother, more natural transitions compared to piecewise linear trajectories
- Non-linear trajectories capture coarticulation effects that CD (context-dependent) triphone models are designed to handle
- When non-linear trajectories are used in monophone MSHMMs, they achieve similar performance to CD triphone models using piecewise linear trajectories
- The smoothing in non-linear formant trajectories captures contextual effects, making explicit CD modeling less critical

### SPG Algorithm Validation
- The first SPG algorithm (known state sequence) has O(T^3 D^3) complexity where T = observation length, D = feature dimensionality
- Can be reduced to O(T^3 D) with diagonal covariance assumption
- Can be further reduced to O(TDL^2) using Cholesky or QR decomposition where L = delta window size
- SPG validation shows trajectories match predicted behavior under various constraint conditions (delta and delta-delta constraints)

## Equations Found

### SPG Algorithm Constraint Equation (Eq 7.7)
$$\boldsymbol{W}^{\top}\boldsymbol{\Sigma}_x^{-1}\boldsymbol{W}\boldsymbol{C} = \boldsymbol{W}^{\top}\boldsymbol{\Sigma}_x^{-1}\boldsymbol{M}^{\top}$$

Where:
- $\boldsymbol{W}$ = transform matrix (static to extended static + dynamic features)
- $\boldsymbol{C}$ = non-linear trajectory in formant space
- $\boldsymbol{M}$ = mean vector sequence from HMMs
- $\boldsymbol{\Sigma}_x$ = variances of the model
- $\boldsymbol{O} = \boldsymbol{WC}$ is the constraint that transformed trajectory matches extended features

## Rules/Algorithms

### Triphone Backoff Scheme (Figure 7.3)
1. For triphone "a-b+c":
   - Check if count of "a-b+c" >= n_min
   - If YES: Use triphone model "a-b+c"
   - If NO: Check if left-context biphone "a-b" count >= n_min
     - If YES: Use biphone "a-b"
     - If NO: Use monophone "b"
2. Backoff frequencies for n_min=50: "a-b+c" -> "a-b" -> "b" = 364, 10714, 8497 respectively

### MSHMM Initialization Steps (Linear/linear)
1. Create conventional HMM counterpart (3-state left-to-right, no-skip) using HTK
2. Estimate linear formant-to-acoustic mappings W_k for each phone class k
3. Initialize MSHMM M_phi for phone phi:
   - Mid-point: c_j = W_k^dagger * mu_j (pseudo-inverse transform of HMM mean)
   - Slope: m_j = 0 (initialized to zero)
   - State duration: uniform, max tau_max = 15 frames
   - Variance: equal to HMM state variance
   - Append mapping W_k and pseudo-inverse to model
4. Re-estimate parameters using Viterbi-type training (Equations 4.28 and 4.29)

### Rescoring with Constrained vs Unconstrained State Sequences
- **Constrained**: Phone boundaries from N-best list forced alignment
- **Unconstrained**: Viterbi alignment with no phone boundary constraints (MSHMMs choose duration)
- Unconstrained sequences generally give better results (especially mappings 6B and 49E)

## Implementation Notes

### For Speech Synthesis (Key Takeaways)
1. **Non-linear trajectory generation**: The SPG algorithm generates smooth formant trajectories that:
   - Capture coarticulation effects automatically
   - Account for target undershoot (short segments don't reach ideal formant values)
   - Maintain continuity constraints between adjacent segments
   - Match natural speech formant trajectories closely

2. **12 PFS Control Parameters**: The work uses 12 parallel formant synthesizer parameters:
   - F1, F2, F3, F4 (formant frequencies)
   - B1, B2, B3, B4 (formant bandwidths)
   - F0 (fundamental frequency)
   - A0 (overall amplitude)
   - AV (voicing amplitude)
   - AH (aspiration amplitude)

3. **Frame rate**: 10ms frames with Holmes formant analyser

4. **Mapping schemes rationale**:
   - 1A: Single linear mapping for all phones (least accurate)
   - 6B: Based on linguistic classes
   - 10C: Based on manner of articulation (Deng & Ma 2000)
   - 10D: Based on source-filter theory features
   - 49E: Separate mapping per phone (most accurate)

5. **Coarticulation modeling**: Non-linear trajectories implicitly model coarticulation, potentially eliminating need for explicit context-dependent rules when combined with appropriate state duration modeling

### Key Insight for Klatt Synthesis
The thesis demonstrates that **smooth formant trajectories** generated by HMM-based parameter generation:
- Significantly improve both synthesis naturalness and recognition accuracy
- Capture coarticulation effects that would otherwise require explicit CD modeling
- Can be used with parallel formant synthesizers (similar to Klatt architecture)
- The smoothing constraints (delta and delta-delta) enforce natural-looking transitions

This suggests that Klatt parameter interpolation should use smooth (not piecewise-constant) transitions, with constraints on both velocity and acceleration of formant movement.
