# Abstract

A new method is introduced for parametric modeling of spectral envelopes when only a discrete set of spectral points is given. This method, which we call discrete all-pole (DAP) modeling, uses a discrete version of the Itakura-Saito distortion measure as its error criterion. One result is a new autocorrelation matching condition that overcomes the limitations of linear prediction and produces better fitting spectral envelopes for spectra that are representable by a relatively small discrete set of values, such as in voiced speech. We present an iterative algorithm for DAP modeling that is shown to converge to a unique global minimum. We also present results of applying DAP modeling to real and synthetic speech. DAP modeling is extended to allow frequency-dependent weighting of the error measure, so that spectral accuracy can be enhanced in certain frequency regions relative to others.

## Interpretation

This paper addresses a fundamental limitation of standard Linear Prediction (LP/LPC) when applied to voiced speech: LP matches autocorrelations of a continuous all-pole model to aliased autocorrelations computed from a discrete harmonic spectrum, leading to biased spectral envelopes, especially at high pitch. DAP solves this by working directly in the discrete spectral domain, matching the model's discrete-frequency autocorrelation to the data's. The resulting iterative algorithm (initialize with LP, then iterate 4-10 times) is practical and provably convergent. For a Klatt synthesizer context, DAP is most relevant to analysis tasks: extracting formant frequencies/bandwidths from speech for parameter estimation, and inverse filtering to obtain glottal flow waveforms. The weighted variant (WDAP) is particularly useful for emphasizing lower formants in coding and synthesis applications.
