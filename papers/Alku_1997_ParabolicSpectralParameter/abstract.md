# Abstract

This study presents a new frequency domain parameter, Parabolic Spectral Parameter (PSP), for the quantification of the glottal volume velocity waveform. PSP is based on fitting a parabolic function to the low-frequency part of a pitch-synchronously computed spectrum of the estimated glottal flow. PSP gives a single numerical value that describes how the spectral decay of an obtained glottal flow behaves with respect to a theoretical limit corresponding to maximal spectral decay. By analyzing speech signals of different phonation types the performance of the new parameter is compared to three commonly used time-based parameters and to one previously developed frequency domain method.

## Interpretation

PSP addresses a real gap in glottal source parameterization: time-domain parameters (OQ, SQ, CQ) are unreliable because they depend on precisely locating glottal opening/closure instants, which is difficult with noise and formant ripple. Existing frequency methods (HRF) use pitch-asynchronous analysis and are affected by F0 changes. PSP solves both problems by using pitch-synchronous spectral analysis and normalizing for F0 effects via the DC-flow reference spectrum. The key result is that PSP achieves perfect monotonic ordering across phonation types (breathy > normal > pressed) for all speakers tested, which none of the comparison parameters achieved. For a synthesizer project, PSP is primarily useful as a validation/diagnostic metric for verifying that synthesized glottal waveforms have appropriate spectral characteristics for intended voice qualities.
