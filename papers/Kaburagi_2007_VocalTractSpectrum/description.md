This paper presents a four-stage articulatory synthesis model that generates vocal tract spectra from phoneme sequences by determining articulatory timing, specifying context-independent phonemic tasks, forming continuous articulatory trajectories via a dynamic model, and estimating spectra from articulatory-acoustic data pairs using weighted nearest-neighbor interpolation. The key contribution is demonstrating that context-dependent coarticulatory variability in both articulatory movements (~1.27 mm error) and vocal tract spectra (~3.44 dB error) emerges naturally from a dynamic articulatory mechanism without requiring context-specific spectral targets, validated on Japanese VCV sequences using simultaneous EMA and acoustic measurements. For formant synthesis, this work provides theoretical support for the idea that simple phonemic targets combined with dynamic transition rules can capture coarticulation effects, though the articulatory-statistical approach is architecturally different from Klatt-style acoustic synthesis.
