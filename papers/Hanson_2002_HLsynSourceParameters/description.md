This paper presents the complete set of equations for deriving Klatt synthesizer source parameters (AV, AF, AH, OQ, TL, DI, F0) from 13 higher-level quasiarticulatory parameters using an equivalent-circuit aerodynamic model of the vocal tract, implemented in the HLsyn system. The key contribution is demonstrating that physically realistic source-filter constraints emerge automatically from the circuit model -- when oral pressure builds during a stop closure, voicing amplitude drops and frication rises without requiring independent parameter control, reducing the synthesis control problem from ~50 unconstrained parameters to 13 physiologically-motivated ones with comprehensive gender-specific speaker constants. This work is directly applicable to Qlatt as a higher-level control layer that could sit between the TTS frontend rules and the Klatt interpreter, enforcing physically grounded parameter constraints and providing the detailed mapping equations that complement Stevens 1991's conceptual framework.
