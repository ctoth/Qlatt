This paper presents SRS (Speech Research System), a flexible computer system for developing text-to-speech rules using a four-level framework: text-modification, conversion (G2P), feature-modification, and parameter rules. The key contribution is the explicit, linguist-friendly rule language with powerful notational devices (exception brackets, phonetic output references, placeholder targets) that enables rapid multi-language TTS development by nonprogrammers. This work is highly relevant to formant synthesis TTS systems like Qlatt, as its parameter rule concepts (percentage-based target positions, linear transitions, duration modification) directly parallel the track generation and semantics evaluation pipeline.
