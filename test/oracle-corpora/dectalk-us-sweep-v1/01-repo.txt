# dectalk-us-sweep-v1: a broad sweep at DECtalk's default rate, voice Paul.
#
# The list is the *.txt files of this directory, read in name order. One
# utterance per line; a line starting with "## " opens a group; "#" lines and
# blank lines are ignored. scripts/oracle/build-sweep-corpus.ts turns them into
# ../dectalk-us-sweep-v1.json (ids are <group>-<number in group>).
#
# A measurement corpus, not a gate. The list was written before any of it was
# exported or compared, and is not to be edited to change a result: add a new
# list instead.
#
# Sources: "repo" is every phrase of test/golden/crystal-tempo-corpus-summary.json,
# declarative-corpus-summary.json and linguistic-master/summary.json. Everything
# else was written for this sweep.
