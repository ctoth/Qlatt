This PhD thesis demonstrates that non-linear formant trajectories generated by Tokuda's Speech Parameter Generation (SPG) algorithm significantly improve speech synthesis naturalness and intelligibility compared to piecewise-constant HMM output. The key finding is that context-independent monophone models with smooth trajectory interpolation can match the coarticulation capture of context-dependent triphone models, achieving 70% DRT word accuracy versus 67% for stepwise parameters and 45% versus 36% naturalness preference. The work provides complete specification of the 12-parameter Parallel Formant Synthesizer (PFS) control set with direct mappings to Klatt parameters, plus the SPG algorithm pseudocode for generating smooth formant tracks from HMM state means.
