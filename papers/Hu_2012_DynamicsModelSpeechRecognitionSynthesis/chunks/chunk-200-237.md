## Key Findings

### Conclusions from Thesis
- Non-linear formant trajectories in the intermediate layer of MSHMMs account for contextual effects (coarticulation) that triphones are designed to accommodate
- Under non-linear trajectory conditions, monophone MSHMMs achieve similar performance to triphone MSHMMs using piecewise linear trajectories
- 46% reduction in Phone Error Rate (PER) achieved for non-linear/linear CD MSHMMs relative to linear/linear under mapping scheme 49E
- Best phone accuracy of 70.4% is comparable to conventional CD HMMs system
- Context-independent MSHMMs benefit more from non-linear formant trajectories than context-dependent MSHMMs

### Speech Synthesis Results (from 2010 paper)
- Non-linear trajectory based synthetic speech achieves 70% word accuracy (vs 67% for piecewise constant)
- Naturalness score: 45% for non-linear vs 35.9% for piecewise constant (statistically significant, p < 0.05)
- DRT test results show non-linear trajectories lead to improvements in intelligibility and naturalness
- Acoustic attributes "sustension" and "compactness" show significant differences between synthesis types

### Future Work Directions
1. Generate non-linear trajectories directly from MSHMMs (instead of auxiliary HMM set)
2. Improve synthesis quality via better Holmes formant analyser or trajectory HMMs
3. Develop non-linear/non-linear MSHMMs (non-linear in both intermediate and mapping layers)
4. Investigate Gaussian mixture MSHMMs for improved acoustic variability modeling
5. Add prosodic structure (duration, pauses, intonation, stress) via Festival feature extraction

## Equations Found

### Delta and Delta-Delta Coefficients (Speech Parameter Generation)
$$\Delta c_t = \frac{c_{t+\theta} - c_{t-\theta}}{2\theta}$$
$$\Delta^2 c_t = \frac{\Delta c_{t+\theta} - \Delta c_{t-\theta}}{2\theta}$$
Where: $c_t$ = static feature vector, $\theta$ = time offset (set to 1)

### Speech Parameter Sequence Transform
$$O = WC$$
Where: $O$ = observation sequence, $W$ = linear transform matrix, $C$ = augmented parameter sequence

### Formant-to-Acoustic Mapping Error Minimization
$$E = \sum_{t=1}^{T} \|Wf_t - y_t\|^2$$
Where: $f = \{f_1, ..., f_T\}$ = formant trajectory, $y = \{y_1, ..., y_T\}$ = acoustic sequence

### Segment Probability (for N-best Rescoring)
$$p(y) = \prod_{n=1}^{N} d_n(\tau_n) \{ \prod_{t=1}^{\tau_n} N(y_{\phi_n+t}; W_{s_n}(f_n(y_{\phi_n+t})), \sigma_n) \}$$
Where: $\phi_n = \sum_{i=1}^{n-1} \tau_i$, $N(y; \mu, \sigma)$ = multivariate Gaussian PDF

### Gaussian Mixture MSHMM (Future Work)
$$p(\mathbf{o}_1^\tau, \mathbf{f}) = p(\mathbf{o}_1^\tau | \mathbf{f})p(\mathbf{f}) = p(\mathbf{f}) \prod_{t=1}^{\tau} p(\mathbf{o}_t | \mathbf{f}(t))$$

$$p(\mathbf{f}) = \sum_{k=1}^{K} w_{ik} \mathcal{N}(\mathbf{f} | \boldsymbol{\nu}_{ik}, \boldsymbol{\eta}_{ik})$$
Where: $w_{ik}$, $\boldsymbol{\nu}_{ik}$, $\boldsymbol{\eta}_{ik}$ = mixture weight, mean, variance for $i$-th state, $k$-th component

## Rules/Algorithms

### Speech Parameter Generator (Tokuda's Algorithm)
```
START program
INITIALIZE length to zero
INITIALIZE mean to zero
INITIALIZE variance to zero
INITIALIZE count to 1
INITIALIZE template transform matrix for a single vector
SET transform matrix to template transform matrix
READ a state sequence
FOR each state in the state sequence
    CALCULATE state duration
    ADD state duration to length
    APPEND state mean to mean
    APPEND state variance to variance
ENDFOR
WHILE count < length
    SHIFT template transform matrix to the right by one column
    APPEND template transform matrix to transform matrix
    ADD 1 to count
ENDWHILE
A = transform matrix transpose * variance inverse * transform matrix
b = transform matrix transpose * variance inverse * mean transpose
COMPUTE C by solving A*C=b using QR decomposition
WRITE C as the speech parameter sequence
END program
```

### MSHMMs N-best List Rescoring
```
START program
INITIALIZE count to zero
GET the size of the nbest list N
CREATE array of size N to hold probabilities for nbest list
INITIALIZE probability array to zero
INITIALIZE temp probability to zero
READ MSHMM model set
READ nbest list
FOR each line in nbest list
    IF line contains speech file name
        EXTRACT speech file name
        READ speech data
        READ trajectory data if doing non-linear MSHMM rescoring
    ELSEIF line equals a dot
        ADD 1 to count
        SET the count-1 element of array to temp probability
        RESET temp probability to zero
        FREE speech data
        FREE trajectory data
        IF count = N
            SEARCH the array to find the highest probability
            WRITE the index of the highest probability
            RESET all elements in probability array to zero
            RESET count=0
        ENDIF
    ELSE
        READ start time, end time, model name and state number
        FOR each model in the MSHMM model set
            IF model matches model name
                CALCULATE segment probability
                ADD segment probability to temp probability
            ENDIF
        ENDFOR
    ENDIF
ENDFOR
END program
```

## Implementation Notes

### Holmes Parallel Formant Synthesiser (HMS)
- Uses 12 PFS control parameters
- Produces high quality synthetic speech given appropriate parameters
- Limited by formant analyser accuracy (written for low-powered computers)
- Can be improved by increasing codebook size for pre-labeled spectra

### Formant-to-Acoustic Mapping Schemes
Five mapping schemes tested:
- **1A**: Phone-independent (all data grouped together)
- **6B**: Grouped by linguistic categories (vowels, nasals, etc.)
- **10C**: Sub-categories based on discrete articulatory regions
- **10D**: Further sub-division of phone classes
- **49E**: Individual phone mappings (most accurate, 67.0% accuracy under 49E)

### Phone Category Groupings (for mapping)

| Category | Definition | Phones |
|----------|------------|--------|
| A | All data | All phones |
| B | Vowels, nasals, etc. | {hh,l,r,w,y}, nasals, {ch,s}, etc. |
| C | Vowels (epi,q,sil), discrete regions | Sub-categorized |
| D | Vowels, (epi,q,sil), detailed sub-categories | Further divided |
| E | 49 individual phones | Each phone separately |

### Key Software Tools Used
- **SEGVit**: Toolkit for MSHMMs training and testing (written in C, Linux)
- **Holmes formant analyser**: Derives 12 PFS control parameters from waveform
- **Holmes formant synthesiser**: Generates synthetic speech from 12 PFS parameters
- **HTK**: Standard HMMs training, N-best list generation and evaluation
- **Matlab**: Speech parameter generation algorithm, formant-to-acoustic mapping
- **PESQ**: ITU-T P.862 reference implementation for objective speech quality evaluation

### DRT (Diagnostic Rhyme Test) Word-Pairs
The DRT uses 96 word-pairs testing 6 acoustic features:
1. **Voicing**: veal/feel, bean/pean, etc.
2. **Nasality**: meat/beat, need/deed, etc.
3. **Sustension**: vee/bee, sheet/cheat, etc.
4. **Sibilation**: zee/thee, cheep/keep, etc.
5. **Graveness**: weed/reed, peak/teak, etc.
6. **Compactness**: yield/wield, key/tea, etc.

### Experimental Settings
- TIMIT corpus downsampled to 8 kHz
- 13 MFCCs with delta and delta-squared coefficients (39 dimensions)
- 25 ms window, 10 ms frame rate
- 49 three-state, left-to-right HMMs (monophone)
- Maximum state duration: 15 frames (tau_max = 15)
- N-best list size: N = 1,000
- Phone accuracy baseline (1-best): 65.7%
- Phone accuracy upper bound (N-best): 77.9%
