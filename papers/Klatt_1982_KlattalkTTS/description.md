This paper presents Klattalk, a complete real-time text-to-speech system combining ~500 letter-to-sound rules, a 1500-word exceptions dictionary, syntactic analysis for prosody, and the Klatt formant synthesizer with 20 control parameters per pitch period. Key contributions include the "hat-pattern" F0 contour strategy, percentage-based duration modification framework, and detailed phonetic component rules for smooth transitions and consonant bursts. This work documents the architecture and design decisions behind one of the most influential TTS systems, directly informing Qlatt's TTS frontend structure, duration rules, and prosody generation.
