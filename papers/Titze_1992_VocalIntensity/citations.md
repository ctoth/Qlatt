## Key Citations for Follow-up

1. **Titze 1992 (Phonation threshold pressure)** -- Companion paper in the same volume defining $P_{th}$ and its aerodynamic derivation. Essential for implementing the threshold pressure model (Eq. 37).
2. **Fant, Liljencrants, and Lin 1985 (LF model)** -- The four-parameter glottal flow model already used in Qlatt. Need to map between LF parameters (Ee, Ta, Te, Tp) and the waveform parameters used here ($\dot{u}_m$, $Q_o$, $Q_s$).
3. **Holmberg, Hillman, and Perkell 1988** -- Primary empirical data source for airflow and pressure measurements across loudness levels. Contains the raw data behind Table I constants.
4. **Ananthapadmanabha 1984** -- Source spectrum analysis methods; basis for the single-parameter spectral model (Eq. 23).
5. **Titze 1988 (Regulation of vocal power)** -- Predecessor paper with the subglottal pressure / glottal width model; provides additional context for the efficiency differences between singers and nonsingers.
