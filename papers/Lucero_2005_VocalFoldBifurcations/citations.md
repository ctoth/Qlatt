## Key Citations for Follow-up

1. **Titze 1988 [1]** - The base model analyzed in this paper. Essential for understanding the mucosal wave oscillator that Lucero analyzes. Already relevant to Qlatt's glottal source modeling.

2. **Lucero 1999 [10]** - Precursor paper showing the hysteresis phenomenon at vocal fold oscillation onset-offset. Provides the experimental/theoretical motivation for the extended model.

3. **Ishizaka & Flanagan 1972 [7]** - The classic two-mass vocal fold model. Comparison point for understanding how bifurcation structure differs between one-mass (mucosal wave) and two-mass models.

4. **Herzel & Knudsen 1995 [11]** - Bifurcation analysis of a different vocal fold model. Useful for comparing bifurcation structures across model types.

5. **Titze 1994 [21]** - Comprehensive reference on voice production principles, including the physical parameters used in the model.
