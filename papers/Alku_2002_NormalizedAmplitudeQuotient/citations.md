## Key Citations (in collection)

- **Alku_1997_ParabolicSpectralParameter** — Authors' earlier work on frequency-domain glottal flow parametrization (PSP). NAQ complements PSP by providing time-domain parametrization.
- **Fant_1985_LFModelGlottalFlow** — The LF model whose parameters NAQ helps reduce/simplify. AQ relates directly to LF's excitation strength E_e.
- **Fant_1988_LFFrequencyDomainInterpretation** — First introduced the ratio f_ac/d_peak as "effective declination time" for LF parameter reduction.
- **Fant_1995_LFModelRevisited** — Defines Rd = (f_ac/d_peak) * F0/110, which equals NAQ/110. NAQ provides a cleaner formulation via the ERP concept.
- **Fant_1997_VoiceSourceConnectedSpeech** — Uses Rd extensively; NAQ provides equivalent parametrization with improved geometric interpretation.
- **Childers_Lee_1991_VoiceQualityFactors** — Frequency-domain voice source quantification approach that NAQ complements.
- **Holmberg_1988_GlottalAirflowPressure** — Provides baseline glottal flow measurements; documents difficulty of time-based parameter extraction that motivates NAQ.
- **Strik_Boves_1992_ControlF0IntensityVoiceQuality** — LF model fitting approach to voice source quantification; NAQ offers a simpler alternative.
