## Key Findings

- **Two types of synthesiser control parameters were compared:**
  1. Piecewise constant PFS control parameters (state mean held constant during state)
  2. Non-linear trajectory PFS control parameters (smooth trajectories via SPG algorithm)

- **Non-linear trajectory model significantly outperforms piecewise constant model:**
  - DRT intelligibility: 70% vs 67% word accuracy (statistically significant, p=0.01)
  - Naturalness subjective: 45% vs 35.9%
  - Naturalness objective (PESQ-LQO): ~1.35 vs ~1.28

- **DRT results by acoustic attribute (6 attributes tested):**
  - Voicing: No significant difference between models
  - Nasality: Non-linear trajectory slightly worse (coarticulation may blur nasal/oral distinction)
  - Sustension, Sibilation, Graveness, Compactness: Non-linear trajectory better
  - "Sibilation" gave best scores for both methods

- **CI (context-independent) models with non-linear trajectory can outperform CD (context-dependent) models with piecewise constant parameters** - demonstrates that the non-linear trajectory model accounts for coarticulation effects

- **Optimal number of HMM states per phone:**
  - Male speakers: 4-state per phone
  - Female speakers: 5-state per phone
  - More states (>6) cause data sparsity problems

- **PESQ correlation with subjective MOS:**
  - Piecewise constant model: r = 0.67
  - Non-linear trajectory model: r = 0.78

- **Speaker adaptation results (MLLR vs MAP):**
  - MLLR works better with small amounts of adaptation data
  - MAP catches up when more adaptation data available
  - Approximately 100 utterances needed to achieve stable speaker similarity

- **Mimicry test findings:**
  - Same speaker, same sentence (S-S): 56.8% similarity
  - Same speaker, different sentence (S-D): 33.5% similarity
  - Different speaker, different sentence (D-D): 33.6% similarity
  - Sentence content significantly affects perceived speaker similarity

- **Over-smoothing problem:** Non-linear trajectories can be "too smooth", producing "muffled" synthetic sounds that may reduce intelligibility despite improving naturalness

## Equations Found

### MLLR Adaptation (Eq. 6.1)
$$\hat{\boldsymbol{\mu}}_j = \boldsymbol{W}\boldsymbol{\xi}_j$$
Where:
- $\hat{\boldsymbol{\mu}}_j$ = adapted mean vector for state $s_j$
- $\boldsymbol{W}$ = $D \times (D+1)$ linear transformation matrix
- $\boldsymbol{\xi}_j = [\omega, \mu_1, \mu_2, \ldots, \mu_D]^\top$ = extended mean vector with bias offset $\omega$
- $D$ = dimension of acoustic observation space

### MAP Estimation (Eq. 6.2)
$$\Lambda_{\text{MAP}} = \arg\max_{\Lambda} P(\Lambda|\boldsymbol{O}) = \arg\max_{\Lambda} p(\boldsymbol{O}|\Lambda)P(\Lambda)$$
Where:
- $P(\Lambda)$ = prior probability of model parameters
- $p(\boldsymbol{O}|\Lambda)$ = likelihood of observations given model

### MAP Mean Update (Eq. 6.3)
$$\hat{\boldsymbol{\mu}} = \frac{\psi}{\psi + \chi}\bar{\boldsymbol{\mu}} + \frac{\chi}{\psi + \chi}\boldsymbol{\mu}$$
Where:
- $\chi$ = weighting of a priori knowledge (SI model parameters)
- $\psi$ = occupation likelihood of adaptation data
- $\bar{\boldsymbol{\mu}}$ = adaptation speech data mean
- $\boldsymbol{\mu}$ = SI model mean

### Paired t-test Statistic (Eq. 6.4)
$$t = \frac{\bar{d}}{s_d / \sqrt{n}}$$
Where:
- $n$ = sample size (number of pairs)
- $s_d$ = standard deviation of differences between paired observations
- $\bar{d}$ = mean difference between paired observations

### Pearson's Correlation Coefficient (Eq. 6.5)
$$r = \frac{\sum_{n=1}^{N}(X_n - \bar{X})(Y_n - \bar{Y})}{\sqrt{\sum_{n=1}^{N}(X_n - \bar{X})^2 \sum_{n=1}^{N}(Y_n - \bar{Y})^2}}$$
Where:
- $X_n, Y_n$ = subjective and objective scores respectively
- $\bar{X}, \bar{Y}$ = average scores

### N-best Recognition (Eq. 7.1)
$$\hat{\mathcal{W}} = \arg\max_{\mathcal{W}} P(\mathcal{W}|\boldsymbol{O}) = \arg\max_{\mathcal{W}} \{p(\boldsymbol{O}|\mathcal{W})P(\mathcal{W})\}$$
Where:
- $\mathcal{W}$ = word sequence
- $\boldsymbol{O}$ = acoustic observation sequence

### Bigram Language Model (Eq. 7.2-7.4)
$$P(w_k|w_1, w_2, \ldots, w_{k-1}) \approx P(w_k|w_{k-1})$$

$$P(\mathcal{W}) = P(w_1)\prod_{k=2}^{K} P(w_k|w_1, \ldots, w_{k-1}) = P(w_1)\prod_{k=2}^{K} P(w_k|w_{k-1})$$

$$P(w_k|w_{k-1}) = \frac{N(w_k, w_{k-1})}{N(w_{k-1})}$$
Where:
- $N(w_k, w_{k-1})$ = count of word pair occurrences
- $N(w_{k-1})$ = count of word occurrences

### Bigram with Back-off (Eq. 7.5)
$$\hat{P}(w_k|w_{k-1}, w_{k_2}) = B(w_{k-1}, w_{k_2})P(w_k|w_{k-1})$$
Where $B(w_{k-1}, w_{k_2})$ is a back-off function for data sparsity

### Segment Probability in MSHMM (Eq. 7.6)
$$p(\boldsymbol{O}|\tilde{\mathcal{W}}_m) = \prod_{n=1}^{N} d_n(\tau_n) \left( \prod_{t=1}^{\tau_n} \mathcal{N}\Big(\boldsymbol{o}_{\phi_n+t}|\boldsymbol{W}_{s_n}\big(\boldsymbol{f}_n(\phi_n + t)\big), \boldsymbol{\Sigma}_n\Big) \right)$$
Where:
- $d_n(\tau_n)$ = duration probability for state $s_n$
- $\phi_n = \sum_{i=1}^{n-1}\tau_i$ = time spent before entering state $s_n$
- $\boldsymbol{W}_{s_n}$ = formant-to-acoustic mapping for state $s_n$
- $\boldsymbol{f}_n$ = trajectory fragment for state $s_n$

## Rules/Algorithms

### TTS Pipeline (Figure 6.1, page 120)
1. Input text (word sequence) + Pronunciation dictionary
2. Text-to-phone conversion
3. Phone sequence fed to PFS-based HMMs store
4. Phone to PFS control parameters conversion
5. Generate PFS control parameters (12 parameters)
6. Parallel formant synthesiser (HMS) generates speech

### Piecewise Constant vs Non-Linear Trajectory Generation
**Piecewise Constant Method:**
1. Determine state sequence from HMM based on expected state duration
2. Expected duration for state $i$: $l_i = \frac{1}{1-a_{ii}}$ where $a_{ii}$ = self-transition probability
3. Generate state mean vector $\boldsymbol{\mu}_i$ for each time frame in state

**Non-Linear Trajectory Method:**
1. Use same state sequence as piecewise constant
2. Apply SPG (Speech Parameter Generation) algorithm to generate smooth trajectory
3. Trajectory respects mean and variance constraints but is continuous

### Diagnostic Rhyme Test (DRT) Protocol
1. 96 word-pairs testing 6 acoustic attributes:
   - Voicing (veal-feel)
   - Nasality (meat-beat)
   - Sustension (vee-bee)
   - Sibilation (zee-thee)
   - Graveness (weed-reed)
   - Compactness (yield-wield)
2. Each participant hears 96 synthetic words
3. Selects matching word from corresponding pair
4. Intelligibility = correct answers / total words (96)

### Semi-Synthetic Speech Generation (Copy Synthesis)
1. Pass original speech through Holmes formant analyser
2. Extract 12 PFS control parameters
3. Feed parameters to HMS parallel formant synthesiser
4. Result: "semi-synthetic" speech retaining original formant dynamics

### Speaker Adaptation Protocol
1. Start with SI (speaker-independent) baseline model
2. Apply MLLR or MAP adaptation with varying amounts of data (0, 5, 9 utterances)
3. MLLR: Estimate transformation matrix $\boldsymbol{W}$ from adaptation data
4. MAP: Interpolate between SI mean and adaptation data mean

## Implementation Notes

### PFS (Parallel Formant Synthesiser) Control Parameters
The system uses 12 control parameters for the Holmes parallel formant synthesiser:
- F1, F2, F3 (formant frequencies)
- B1, B2, B3 (formant bandwidths)
- AV (voicing amplitude)
- AH (aspiration amplitude)
- AF (frication amplitude)
- Plus additional parameters for source control

The HMMs model these 12 parameters plus their delta coefficients (24-dimensional feature vector).

### Key Implementation Considerations

1. **State Duration from HMM:**
   - Expected duration: $l_i = \frac{1}{1-a_{ii}}$
   - State sequence: $\hat{\mathbf{x}} = \{s_1 \times l_1, \ldots, s_N \times l_N\}$

2. **Trajectory Generation:**
   - Linear/piecewise: Hold state mean constant
   - Non-linear: Apply SPG algorithm for smooth interpolation

3. **Model Selection:**
   - CI models: 49 phones + 1 silence model
   - CD models: 6575 tied triphone models
   - States per phone: 3-6 (optimal at 4-5)

4. **Evaluation Metrics:**
   - DRT for intelligibility (word-level accuracy)
   - MOS for naturalness (5-point scale)
   - PESQ for objective quality (ITU-T P.862)
   - Similarity score for speaker adaptation (10-point scale)

5. **Data Requirements:**
   - Training: TIMIT corpus (4620 full training, 3260 male, 1360 female)
   - Adaptation: 5-9 utterances per speaker (limited by TIMIT)
   - For stable speaker similarity: ~100 utterances recommended

### Practical Findings for Synthesis Implementation

1. **Non-linear trajectories improve naturalness more than intelligibility** - the smoothing effect is more beneficial for overall quality perception than for phoneme discrimination

2. **Over-smoothing risk:** F3 trajectories tend to be over-smoothed, which may cause "muffled" sounding speech - consider reducing smoothing for higher formants

3. **Nasality is harder to model with smooth trajectories** - coarticulation blurs nasal/oral distinction; may need special handling for nasal consonants

4. **CI models with trajectory can match CD models** - suggests that trajectory modeling captures coarticulation effects, potentially simplifying model inventory requirements
