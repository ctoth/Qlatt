A comprehensive textbook covering both speech synthesis and recognition, with particular depth on formant synthesis by rule using the Holmes-Mattingly-Shearme (HMS) table-driven system and the Holmes (1983) parallel-formant synthesizer architecture. The book details the complete TTS pipeline from text normalization through prosody generation to waveform synthesis, including duration modeling, F0 contour generation (Fujisaki and Pierrehumbert approaches), and the trade-offs between cascade and parallel formant synthesizer topologies. Directly relevant to Qlatt's formant synthesizer architecture, rule-based parameter generation, and TTS pipeline design.
