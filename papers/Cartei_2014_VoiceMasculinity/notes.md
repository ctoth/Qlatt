# What Makes a Voice Masculine: Physiological and Acoustical Correlates of Women's Ratings of Men's Vocal Masculinity

**Authors:** Valentina Cartei, Rod Bond, David Reby
**Year:** 2014
**Venue:** Hormones and Behavior (Accepted Manuscript)
**DOI:** 10.1016/j.yhbeh.2014.08.006

## One-Sentence Summary
Uses a two-level path model to show that testosterone's effect on perceived vocal masculinity is entirely mediated by F0, while height's effect on perceived masculinity is partially mediated by both F0 and formant spacing (deltaF).

## Problem Addressed
The relationships between physiological characteristics (testosterone, height), acoustic parameters (F0, formant spacing), and perceptual judgments of vocal masculinity had not been jointly modeled to determine which acoustic cues mediate the physiology-perception link.

## Key Contributions
- Path analysis showing testosterone -> F0 -> perceived masculinity (full mediation)
- Path analysis showing height -> F0 + deltaF -> perceived masculinity (partial mediation)
- F0 is a more salient cue to masculinity than deltaF for listeners
- F0 and deltaF are largely independent acoustic dimensions (consistent with source-filter theory)

## Methodology
- 37 adult heterosexual males, audio-recorded on speech tasks
- 20 adult heterosexual female listeners rated masculinity
- Two-level path analysis (speaker within listener)
- Physiological measures: salivary testosterone, height
- Acoustic measures: F0, deltaF (formant spacing from first 4 formants)
- Perceptual measure: masculinity ratings on continuous scale

## Key Path Coefficients

### Testosterone -> Acoustics -> Masculinity
- Testosterone -> F0: negative correlation (higher T = lower F0)
- F0 -> perceived masculinity: rho = -.53 (p < .001) — lower F0 = more masculine
- Testosterone -> perceived masculinity (indirect via F0): rho = -.25 (p < .001)
- Testosterone -> perceived masculinity (direct): rho = .02, p = .562 — **NOT significant**
- **Conclusion: Testosterone-masculinity link is ENTIRELY mediated by F0**

### Height -> Acoustics -> Masculinity
- Height -> F0: weak negative correlation (rho = -.19, p < .001)
- Height -> deltaF: negative correlation (taller = lower formant spacing)
- Height -> perceived masculinity (total effect): rho = .30 (p < .001)
- Height -> perceived masculinity (direct): rho = .13 (p < .001) — still significant
- **Conclusion: Height-masculinity link is PARTIALLY mediated by F0 and deltaF**

### F0 vs deltaF as Masculinity Cues
- F0 correlation with perceived masculinity: rho = -.53 (p < .001)
- deltaF correlation with perceived masculinity: rho = -.33 (p < .001)
- F0 and deltaF correlation with each other: rho = .05 (p = .155) — NOT correlated
- **F0 is a stronger cue to perceived masculinity than deltaF**

## Parameters

| Variable | Role | Effect on Masculinity |
|----------|------|----------------------|
| F0 (mean) | Primary acoustic cue | rho = -.53 (lower = more masculine) |
| deltaF (formant spacing) | Secondary acoustic cue | rho = -.33 (lower = more masculine) |
| Testosterone (salivary) | Physiological driver | Mediated entirely by F0 |
| Height | Physiological driver | Partially mediated by F0 and deltaF |

## Results Summary
1. Lower F0 and narrower formant spacing both predict higher masculinity ratings
2. F0 is a more salient masculinity cue than deltaF for female listeners
3. Testosterone's effect on perceived masculinity is fully mediated by F0
4. Height has a direct effect on perceived masculinity beyond what F0 and deltaF mediate
5. F0 and deltaF are uncorrelated, consistent with source-filter independence
6. F0 mainly signals hormonal quality; deltaF mainly signals body size

## Limitations
- Cross-sectional design
- Only 37 male speakers
- Read speech only (not spontaneous)
- Only F0 and deltaF measured — no voice quality, spectral tilt, or temporal parameters
- Salivary testosterone measured at single time point

## Testable Properties
- F0 and deltaF should be uncorrelated in male voice samples (source-filter independence)
- Lower F0 must predict higher masculinity ratings (monotonic negative relationship)
- Lower deltaF must predict higher masculinity ratings (monotonic negative relationship)
- F0 effect size on masculinity should be larger than deltaF effect size

## Relevance to Project
For the Qlatt speaker personality system, this paper establishes the acoustic parameters that matter for perceived vocal masculinity: primarily F0, secondarily formant spacing. The finding that these are independent dimensions means they can be manipulated independently in speaker profiles. A "masculine" voice preset should lower F0 and narrow formant spacing, while the source-filter independence means these changes won't interact acoustically.
