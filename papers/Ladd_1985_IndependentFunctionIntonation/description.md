Three perception experiments using digitally resynthesized German utterances demonstrate that intonation contour type, F0 range, and voice quality function as largely independent acoustic channels for signaling speaker affect. The paper provides an explicit formula for scaling F0 range relative to a speaker floor (Fr) using a single range parameter R, and shows that F0 range effects on affective judgments are continuous rather than categorical. The findings support modeling these three prosodic dimensions as orthogonal controls in a speech synthesizer.
