## Key Citations for Follow-up

- **[4] Cummings 1992 (PhD dissertation)**: Primary data source for all style parameters. Contains the beta function glottal model and the statistical analyses from which Tables 1-4 are derived. Essential for understanding the derivation of the scaling factors.
- **[7] Klatt 1980**: Already in collection. The synthesizer specification this paper builds on.
- **[9] Klatt & Klatt 1990**: Already in collection. Describes the L-F source implementation in KLSYN88A that this paper uses.
- **[6] Hansen 1988 (PhD dissertation)**: Analysis of stressed and noisy speech -- complementary dataset on speech under adverse conditions.
- **[5] Fant 1970**: Already in collection. Source-filter theory foundation.
