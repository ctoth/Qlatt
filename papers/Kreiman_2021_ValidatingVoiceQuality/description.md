This paper validates a psychoacoustic model of voice quality that treats quality as perceptually integral rather than decomposing it into separate dimensions like breathiness and roughness, using parameters for the harmonic source (four-piece spectral slope: H1-H2, H2-H4, H4-2kHz, 2kHz-5kHz), inharmonic source (four-band noise spectrum plus HNR), vocal tract (11 formants and 3 zeros with bandwidths), fundamental frequency, and amplitude. In experiment 1, analysis-by-synthesis copies of 200 voices (normal and pathological) were perceptually indistinguishable from originals for 198/200 tokens (d' < 2.10), demonstrating parameter sufficiency; in experiment 2, removing any one harmonic source parameter significantly degraded perceptual match, demonstrating necessity. For formant synthesis, the validated four-piece source spectral model provides a perceptually grounded decomposition of the glottal spectrum that complements LF-model parameterization, the high-frequency source slope (H4-5kHz) emerges as the most critical parameter for breathiness/brightness perception, and the finding that source-tract interaction is unavoidable below H4 has implications for cascade formant amplitude calibration.
