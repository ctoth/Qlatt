# Holmes, Mattingly & Shearme 1964 - Speech Synthesis by Rule

First comprehensive system for synthesizing continuous English speech "by rule" using a computer programme driving a parallel formant synthesizer. The system uses phonetic element tables containing steady-state formant targets and transition specifications, with a dominance-based algorithm that calculates boundary values and linearly interpolates formant and amplitude trajectories between elements. Foundational work establishing the target-and-transition model with rank-based dominance that influenced all subsequent rule-based formant synthesizers including Klatt's.
