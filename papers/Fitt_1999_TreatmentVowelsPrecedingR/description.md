Works out the concrete rule formalism for the Unisyn keyword lexicon's treatment of vowels before 'r', anchored by two explicit encoding criteria (Principle I: encode a distinction if phonemic in any accent; Principle II: derive by post-lexical rule if predictable from environment, overriding Principle I on conflict) plus generative-phonology-style slash-context notation and worked rewrite rules. Surveys every rhotic-adjacent Wells keyword (NURSE, NEAR, SQUARE, START, NORTH, FORCE, CURE, LETTER, PRICE, CHOICE, MOUTH) with frequency data from a 110,000-word dictionary. This is the primary source for the actual rule syntax and per-accent phoneme-mapping mechanics behind the Unisyn architecture.
