# Turk & Shattuck-Hufnagel 2000 — Word-Boundary-Related Duration Patterns in English

This paper systematically tests five proposed word-level duration adjustment mechanisms (word-final lengthening, word-initial lengthening, polysyllabic shortening, accentual lengthening, and syllable ratio equalization) using segmentally controlled English triads where word boundary location varies while phonemic content remains constant. The key finding is that word-final lengthening is NOT supported as a separate mechanism; the duration patterns previously attributed to it are better explained by word-initial lengthening, symmetric polysyllabic shortening, accentual lengthening, and syllable ratio equalization operating on vowel nuclei. For TTS duration modeling, this provides evidence against implementing word-final lengthening rules and in favor of word-initial lengthening (~5-15 ms on onset consonants), with reduced effects at function word boundaries.
