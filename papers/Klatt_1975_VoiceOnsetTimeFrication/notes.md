# Klatt 1975 - Voice Onset Time, Frication, and Aspiration in Word-Initial Consonant Clusters

## Key Findings for Synthesis

### VOT = Burst Duration + Aspiration Duration

The VOT interval for voiceless plosives divides into two phases:
1. **Frication burst** - noise generated at the expanding oral constriction
2. **Aspiration** - noise generated at the glottis

The aspiration duration is approximately constant across /p, t, k/ in comparable phonetic environments. The burst duration increases from /p/ to /t/ to /k/.

### Key VOT Generalizations

- **Place of articulation effect**: VOT increases /p/ < /t/ < /k/ (approximately 47, 65, 70 ms for singletons before vowels)
- **Voiced plosives**: Mean VOT ~18 ms before vowels, ~23 ms before sonorant consonants
- **Voiceless plosives (not preceded by /s/)**: Mean VOT ~61 ms before vowels, ~81 ms before sonorant consonants
- **After /s/**: VOT is drastically reduced (similar to voiced plosives): /sp/ 12, /st/ 23, /sk/ 30 ms
- **Before sonorants**: VOT increases by 10-40 ms relative to pre-vocalic position
- **Before high vowels**: VOT is 15% longer than before mid/low vowels

### Spectral Characteristics of Burst vs. Aspiration

- **Aspiration**: Weaker in intensity, excites all but first formant (15-25 dB less intense in F1 region due to abducted vocal folds increasing B1; Stevens & Klatt 1974)
- **/t/ burst**: Strong excitation of 4th, 5th, and higher formants
- **/k/ burst**: Continuous energy at F3 before front vowels, or continuous at F2 before back vowels
- **/p/ burst**: Frequently too weak and spectrally diffuse to differentiate from aspiration

### Six Perceptual Cues to Voiced/Voiceless Distinction (Figure 4)

1. **Voice onset time** - >20-25 ms delay = voiceless; <20 ms = voiced
2. **Low-frequency energy** - presence of F1 energy at release = voiced
3. **Burst loudness** - voiceless bursts 3-6 dB louder
4. **Fundamental frequency** - F0 ~5% higher after voiceless plosives; 15% difference immediately post-onset
5. **Segmental duration** - vowel/sonorant preceding voiceless plosive is shorter (up to 34% in phrase-final)
6. **Prevoicing** - F1 ~200 Hz during closure for voiced plosives preceded by voiced segment

### VOT Perceptual Boundary

- VOT > ~20-25 ms: burst and voicing onset perceived as separate events = voiceless
- VOT < ~20 ms: perceived as simultaneous = voiced
- First-formant onset frequency trades with VOT: phoneme boundary shifts up to 15 ms depending on F1 trajectory (Stevens & Klatt 1974)

### Laryngeal Control Rules (Figure 5)

Five rules for motor commands to laryngeal muscles:

1. If /p,t,k/ preceded by voiced segment: abduct and stiffen vocal folds so vibrations cease a few ms before closure; initiate glottal closing at a fixed time after burst end
2. If /p,t,k/ preceded by voiceless segment: keep vocal folds abducted and stiff during closure
3. If /b,d,g/ preceded by voiced segment: keep vocal folds approximated and slack throughout closure
4. If /b,d,g/ preceded by voiceless segment: time adduction command so vocal folds are approximated before plosive release
5. If /p,t,k/ preceded by /s/ in same word: begin vocal fold closure earlier so voicing onset occurs a few ms after frication burst ends

### Appendix: VOT Prediction Rules for Sentences

**Voiced plosives /b, d, g/:**
- Use Table 1 average values
- If preceded by voiceless consonant: multiply by 1.3
- If preceded by nasal: multiply by 0.8

**Voiceless plosives /p, t, k/ in prestressed clusters:**
- Use Table 1 average values directly

**Voiceless plosives /p, t, k/, not prestressed:**

*Word-initial:*
- If preceded by voiceless consonant or silence: multiply Table 1 values by 0.9
- Otherwise: multiply Table 1 values by 0.7

*Word-medial and word-final:*
- If preceded by voiceless consonant: multiply Table 1 value by 0.7
- Otherwise: multiply Table 1 value by 0.4
- If preceded by homorganic nasal consonant: set VOT to zero
- /t/ becomes a glottal stop (VOT = 0) if followed by syllabic /n/ or if preceded by /n/ and followed by /m, n, l/
- /t/ becomes a flap intervocalically (no burst and VOT = 0)
- There is a burst but essentially no aspiration if the plosive is followed by a fricative

### Connected Speech Effects

- VOT is about 10-15 ms shorter if the segment before /p,t,k/ is a nasal
- Prestressed position: median VOT of /t 'V/ = 60 ms in discourse (vs 53 ms in carrier sentence)
- VOT 4 ms longer in discourse than carrier sentence on average for prestressed clusters
- VOT shorter in postvocalic and preunstressed positions by ~15 ms (word-initial intervocalic) to ~35 ms (other intervocalic)
- Word-boundary location influences VOT even for segments not normally distinguished suprasegmentally

## Implementation Notes for Klatt Synthesizer

### Synthesizer Parameters Affected

- **AF (frication amplitude)**: Controls burst noise amplitude during frication phase
- **AH (aspiration amplitude)**: Controls aspiration noise amplitude during aspiration phase
- **AV (voicing amplitude)**: Controls voice onset timing
- **F1 bandwidth (B1)**: Wider during aspiration due to glottal opening (~15-25 dB less F1 energy)
- **Duration**: VOT values directly set the timing of AV onset relative to burst onset

### Implementation Strategy

1. At plosive release: set AF to burst level (place-dependent spectrum)
2. After burst duration: transition AF to 0, set AH to aspiration level
3. After aspiration duration (= VOT - burst duration): set AV to voicing level, narrow B1
4. For voiced plosives: set AV onset at release + small VOT (~11-27 ms)
5. For /s/-plosive clusters: use reduced VOT values from Table 1
6. Use Appendix rules to scale Table 1 VOT values by sentence context

### Burst Spectral Shaping

- /t/: High-frequency emphasis (F4, F5 region), brief transient
- /k/: Energy concentrated at F2-F3 (place-dependent), longer burst
- /p/: Weak, diffuse spectrum, very short burst (~11 ms, estimated from /b/)
- Voiced plosive bursts: 3-6 dB weaker than voiceless equivalents
