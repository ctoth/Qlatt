# Towards an Improved Model of Dynamics for Speech Recognition and Synthesis

**Authors:** Hongwei Hu
**Year:** 2012
**Venue:** PhD Thesis, University of Birmingham
**DOI/URL:** http://etheses.bham.ac.uk/id/eprint/3174

## One-Sentence Summary

This thesis demonstrates that non-linear formant trajectories generated by Tokuda's Speech Parameter Generation (SPG) algorithm significantly improve both speech synthesis naturalness (70% vs 67% DRT accuracy) and recognition performance by capturing coarticulation effects that would otherwise require context-dependent triphone models.

## Problem Addressed

Conventional HMMs treat speech as piecewise-constant acoustic frames, ignoring the continuous, non-linear dynamics of articulatory movement. This fails to capture:
- Coarticulation effects spanning multiple segments
- Target undershoot when segments are too short to reach ideal formant values
- Natural formant transitions that vary smoothly rather than stepping between targets

The thesis explores whether non-linear trajectory models in an intermediate formant-based layer can better capture speech dynamics for both recognition and synthesis.

## Key Contributions

1. **Non-linear trajectory generation for formant synthesis** using Tokuda's SPG algorithm, producing smooth trajectories that outperform piecewise-constant HMM means
2. **Multiple-level Segmental HMM (MSHMM) framework** with an intermediate 12-PFS formant layer between acoustic observations and phonetic states
3. **Demonstration that CI models with non-linear trajectories match CD triphone performance** - proving trajectory smoothing captures coarticulation
4. **Empirical validation** through DRT intelligibility tests (70% vs 67%), naturalness scores (45% vs 36%), and recognition experiments (up to 4.9% phone accuracy improvement)
5. **Complete 12-PFS parameter specification** for Holmes parallel formant synthesizer integration

## Methodology

### MSHMM Architecture

```
Acoustic layer (MFCCs) ← Formant-to-acoustic mapping W_k ← Formant layer (12 PFS)
                                                              ↑
                                                    Linear/Non-linear trajectories
                                                              ↑
                                                    Finite state process (phones)
```

The system uses:
- **Intermediate layer**: 12 PFS control parameters (formant-based)
- **Linear trajectory model**: f_j(t) = (t - midpoint) * slope + center
- **Non-linear trajectory**: Generated by SPG algorithm enforcing static/dynamic feature consistency
- **Phone-class-dependent mappings**: 1A (single), 6B, 10C, 10D, 49E (per-phone)

### SPG (Speech Parameter Generation) Algorithm

Converts piecewise-constant HMM means into smooth non-linear trajectories by:
1. Constructing augmented observation O = [c, Δc, Δ²c]
2. Building transform matrix W relating O to static features C
3. Solving linear system R_x * C = r_x where R_x = W^T * Σ_x^{-1} * W

## Key Equations

### Linear Trajectory Model (Eq. 4.1)
$$\mathbf{f}_j(t) = (t - \bar{t})\mathbf{m}_j + \mathbf{c}_j$$

Where:
- $\bar{t} = (\tau + 1)/2$ is the midpoint of segment duration $\tau$
- $\mathbf{m}_j$ is the slope vector
- $\mathbf{c}_j$ is the midpoint (target) vector

### Delta Coefficients (Eq. 5.1-5.2)
$$\Delta \mathbf{c}_t = \frac{\sum_{\theta=1}^{\Theta} \theta(\mathbf{c}_{t+\theta} - \mathbf{c}_{t-\theta})}{2\sum_{\theta=1}^{\Theta}\theta^2}$$

$$\Delta^2 \mathbf{c}_t = \frac{\sum_{\theta=1}^{\Theta} \theta(\Delta\mathbf{c}_{t+\theta} - \Delta\mathbf{c}_{t-\theta})}{2\sum_{\theta=1}^{\Theta}\theta^2}$$

Where $\Theta$ is the regression window length (typically 2).

### Static-Dynamic Relationship (Eq. 5.7)
$$\mathbf{O} = \mathbf{W}\mathbf{C}$$

Where:
- $\mathbf{O}$ is augmented observation (static + delta + delta-delta), dimension 3DT
- $\mathbf{C}$ is static features, dimension DT
- $\mathbf{W}$ is the 3DT × DT transformation matrix

### SPG Linear System (Eq. 5.15-5.17)
$$\mathbf{R}_x \mathbf{C} = \mathbf{r}_x$$

Where:
- $\mathbf{R}_x = \mathbf{W}^\top \boldsymbol{\Sigma}_x^{-1} \mathbf{W}$ (banded matrix for efficient solving)
- $\mathbf{r}_x = \mathbf{W}^\top \boldsymbol{\Sigma}_x^{-1} \boldsymbol{\mu}_x$
- $\boldsymbol{\mu}_x$ is augmented mean vector from state means
- $\boldsymbol{\Sigma}_x$ is block-diagonal covariance from state covariances

### Expected State Duration
$$l_i = \frac{1}{1-a_{ii}}$$

Where $a_{ii}$ is the self-transition probability for state $i$.

## Implementation Details

### SPG Algorithm Pseudocode

```
START program
INITIALIZE length to zero
INITIALIZE mean to zero
INITIALIZE variance to zero
SET transform matrix W to template (for single vector)

READ state sequence
FOR each state in sequence
    CALCULATE state duration from self-transition probability
    ADD duration to length
    APPEND state mean to mean vector
    APPEND state variance to variance
ENDFOR

// Build full transform matrix
WHILE count < length
    SHIFT template transform matrix right by one column
    APPEND to transform matrix
    ADD 1 to count
ENDWHILE

// Solve linear system
A = W^T * variance_inverse * W      // Banded matrix
b = W^T * variance_inverse * mean^T
COMPUTE C by solving A*C=b using QR decomposition
WRITE C as smoothed parameter sequence
END program
```

### Data Structures

```
MSHMM_State:
  - midpoint_vector: float[D]     // D-dimensional intermediate space
  - slope_vector: float[D]        // Linear trajectory slope
  - covariance: float[D x D]      // Or diagonal for efficiency
  - phone_class: int              // Index into K mapping matrices
  - duration_mean: float          // Gaussian duration parameters
  - duration_variance: float

FormantToAcousticMapping:
  - W_k: float[N x M]             // N=acoustic dim, M=formant dim
  - phone_class: int

SPG_Context:
  - W: float[3DT x DT]            // Static-to-augmented mapping
  - mu_x: float[3DT]              // Augmented mean vector
  - Sigma_x: float[3DT x 3DT]     // Block diagonal covariance
  - R_x: float[DT x DT]           // Banded matrix for solving
  - r_x: float[DT]                // RHS of linear system
```

### Initialization Procedure (Linear/Linear MSHMM)

1. Create conventional HMM counterpart (3-state left-to-right) using HTK
2. Estimate linear formant-to-acoustic mappings W_k for each phone class
3. Initialize MSHMM for phone φ:
   - Midpoint: c_j = W_k^† * μ_j (pseudo-inverse of HMM mean)
   - Slope: m_j = 0 (initialized to zero)
   - Duration: uniform, max τ_max = 15 frames
   - Variance: equal to HMM state variance
4. Re-estimate parameters using Viterbi-type training

### Edge Cases

- **Boundary handling for delta coefficients**: Replicate first/last feature vector Θ times at boundaries
- **τ_max selection**: Must accommodate all phone durations (15 frames for TIMIT)
- **Numerical stability**: Use SVD for pseudo-inverse, add small diagonal for regularization
- **Over-smoothing**: F3 trajectories can be "too smooth", producing muffled sounds

### Holmes Formant Analysis Pipeline

1. Sample speech at 8000 Hz (4 kHz bandwidth)
2. Apply pitch-synchronous Fourier analysis → 31-dim log power spectrum every 10ms
3. Compare to codebook of 150 reference spectra using Euclidean distance
4. Select shortlist of 6 best-matching spectra
5. Apply DP frequency warping to find best match
6. Parabolic interpolation for fine frequency adjustment
7. DP time smoothing to minimize trajectory discontinuity
8. Determine amplitudes at estimated formant frequencies

## Key Experimental Results

### DRT (Diagnostic Rhyme Test) Intelligibility

| Method | Word Accuracy | Statistical Significance |
|--------|--------------|-------------------------|
| Non-linear trajectory | **70%** | p=0.01 |
| Piecewise constant | 67% | baseline |

By acoustic attribute:
- **Sibilation**: Best for both methods
- **Nasality**: Non-linear slightly worse (coarticulation blurs distinction)
- **Sustension, Graveness, Compactness**: Non-linear better
- **Voicing**: No significant difference

### Naturalness

| Method | Subjective MOS | PESQ-LQO |
|--------|---------------|----------|
| Non-linear trajectory | **45%** | ~1.35 |
| Piecewise constant | 35.9% | ~1.28 |

PESQ correlation with subjective MOS:
- Piecewise constant: r = 0.67
- Non-linear trajectory: r = 0.78

## Results Summary

1. **Non-linear trajectories improve naturalness more than intelligibility** - smoothing benefits overall quality perception more than phoneme discrimination
2. **Over-smoothing risk**: F3 particularly susceptible; may need reduced smoothing for higher formants
3. **Nasality harder with smooth trajectories** - coarticulation blurs nasal/oral distinction
4. **CI + trajectory ≈ CD + piecewise** - trajectory modeling captures coarticulation, simplifying model requirements
5. **~100 utterances needed** for stable speaker adaptation

## Limitations

1. **Holmes formant analyser quality**: Written for low-powered computers, limited codebook (150 spectra)
2. **Semi-synthetic speech inadequate for speaker identity**: Copy synthesis doesn't preserve voice characteristics well
3. **Over-smoothing problem**: Non-linear trajectories can produce "muffled" sounds
4. **Prosodic modeling absent**: No duration, pause, intonation, or stress variation beyond HMM durations
5. **Single speaker dependency**: Better results with speaker-dependent models but limited adaptation data

## Relevance to Klatt Synthesis

### Direct Applications

1. **12 PFS → Klatt mapping**: The 12 PFS parameters map directly to Klatt:
   - F1, F2, F3 → Klatt F1, F2, F3
   - A1, A2, A3 → Klatt parallel branch amplitudes
   - FN (250 Hz) → Klatt F_NZ/F_NP region
   - AHF → Klatt AH (high-frequency aspiration)
   - V → Klatt AV (voicing amplitude)
   - F0 → Klatt F0
   - MS → Klatt OQ (open quotient)

2. **Trajectory smoothing for Klatt parameter tracks**:
   - Apply SPG algorithm to Klatt parameter tracks post-generation
   - Enforce delta/delta-delta constraints for natural transitions
   - Use phone-class-dependent smoothing strength

3. **Coarticulation capture**:
   - Non-linear trajectories eliminate need for explicit CD rules
   - Formant transitions emerge from dynamic constraints
   - Target undershoot automatic for short segments

4. **Frame rate**: 10ms frames match typical Klatt update rate

### Implementation Recommendations

1. **Don't step between phoneme targets** - use smooth interpolation with velocity/acceleration constraints
2. **Higher formants need less smoothing** - F3 over-smoothing produces muffled output
3. **Nasals may need special handling** - smooth trajectories blur nasal/oral distinction
4. **Phone-class mappings matter** - 49 per-phone mappings outperform single universal mapping
