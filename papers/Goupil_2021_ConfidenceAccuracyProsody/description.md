This paper empirically disentangles the contributions of subjective confidence versus objective accuracy to speech prosody by analyzing verbal responses in a non-social psychophysical task. The key finding is that intonation and duration reflect subjective confidence (LHL% pattern for confident, HLH% for uncertain), while loudness primarily reflects accuracy, with these signatures appearing even without an audience and being decodable by machine classifiers at ~55-60% accuracy. For formant synthesis, this provides concrete guidance on implementing epistemic prosody: confident speech should have rising-then-falling F0 contours with longer duration, while uncertain speech should have falling-then-rising F0 with terminal rises.
