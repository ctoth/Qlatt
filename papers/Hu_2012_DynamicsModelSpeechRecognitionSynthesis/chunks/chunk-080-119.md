## Key Findings

- **MSHMM framework** provides an intermediate "articulatory" layer between acoustic observations and hidden states, enabling explicit dynamics modeling within segments
- **Linear trajectory model**: Each state is associated with a midpoint vector **c** and slope vector **m**, specifying a linear trajectory in the intermediate space
- **Formant-to-acoustic mapping W_k** is phone-class-dependent (K categories), estimated using least-squares from matched formant and acoustic data
- **Segmental Viterbi decoder** complexity is O(N^2 * T * tau_max), where tau_max is maximum state duration (set to 15 frames for TIMIT)
- **Triphone MSHMM with 3FF intermediate representation and 49 articulatory-to-acoustic mappings** has 25% fewer parameters than conventional HMM but gives superior performance
- **No evidence that female speech recognition is affected by formant analysis difficulties** (Russell et al. 2007)
- **SPG algorithm** (Tokuda et al. 1995, 2000) smooths piecewise constant mean trajectories by enforcing constraints between static and dynamic features
- **Non-linear trajectories are more realistic** for describing formant dynamics than piecewise linear trajectories
- **Trajectory HMM** produces same mean trajectory as SPG algorithm but with an alternative probabilistic interpretation
- **HMM-based synthesis** can produce intelligible speech comparable to concatenative systems (Festival) but both are lower quality than natural speech
- **MSD-HMM** (Multi-Space Distribution) handles F0 modeling by combining continuous distributions for voiced regions with discrete mass for unvoiced

## Equations Found

### Linear Trajectory Model (Eq. 4.1)
$$\mathbf{f}_j(t) = (t - \bar{t})\mathbf{m}_j + \mathbf{c}_j$$
Where: $\bar{t} = (\tau + 1)/2$ is the midpoint of segment duration $\tau$, $\mathbf{m}_j$ is slope vector, $\mathbf{c}_j$ is midpoint vector

### State Output Probability (Eq. 4.2)
$$b_j(\mathbf{o}_1^\tau) = \prod_{t=1}^{\tau} \mathcal{N}\left(\mathbf{o}_t | \mathbf{W}_k(\mathbf{f}_j(t)), \mathbf{\Sigma}_j\right)$$
Where: $\mathcal{N}$ is Gaussian PDF with mean $\mathbf{W}_k(\mathbf{f}_j(t))$ and covariance $\mathbf{\Sigma}_j$

### Segmental Viterbi Recursion (Eq. 4.12)
$$\hat{\alpha}_i(t) = \max_j \max_\tau \begin{cases} \pi_j b_j(\mathbf{o}_1^\tau) & \text{for } t = \tau \\ \hat{\alpha}_j(t-\tau) a_{ji} b_i(\mathbf{o}_{t-\tau+1}^t) & \text{for } t > \tau \end{cases}$$
Where: $\pi_j$ is initial state probability, $a_{ji}$ is transition probability, $1 \leq \tau \leq \tau_{max}$

### Formant-to-Acoustic Mapping Estimation (Eq. 4.17)
$$\mathbf{W}_k = \mathbf{O}\mathbf{R}^\dagger$$
Where: $\mathbf{R}^\dagger$ is pseudo-inverse of formant matrix $\mathbf{R}$, $\mathbf{O}$ is acoustic observation matrix

### ML Midpoint Estimation (Eq. 4.23)
$$\hat{\mathbf{c}}_j = \frac{1}{\tau}(\mathbf{\Psi}_j \mathbf{W}_k)^\dagger \mathbf{\Psi}_j \sum_{t=1}^{\tau} \mathbf{o}_t$$
Where: $\mathbf{\Psi}_j = \mathbf{\Sigma}_j^{-1/2}$

### ML Slope Estimation (Eq. 4.27)
$$\hat{\mathbf{m}}_j = \frac{1}{\sum_{t=1}^{\tau}(t-\bar{t})^2} (\mathbf{\Psi}_j \mathbf{W}_k)^\dagger \mathbf{\Psi}_j \sum_{t=1}^{\tau}(t-\bar{t})\mathbf{o}_t$$

### Delta Coefficients (Eq. 5.1, 5.2)
$$\Delta \mathbf{c}_t = \frac{\sum_{\theta=1}^{\Theta} \theta(\mathbf{c}_{t+\theta} - \mathbf{c}_{t-\theta})}{2\sum_{\theta=1}^{\Theta}\theta^2}$$

$$\Delta^2 \mathbf{c}_t = \frac{\sum_{\theta=1}^{\Theta} \theta(\Delta\mathbf{c}_{t+\theta} - \Delta\mathbf{c}_{t-\theta})}{2\sum_{\theta=1}^{\Theta}\theta^2}$$
Where: $\Theta$ is regression window length

### Static-Dynamic Relationship (Eq. 5.7)
$$\mathbf{O} = \mathbf{W}\mathbf{C}$$
Where: $\mathbf{O}$ is augmented observation (static + delta + delta-delta), $\mathbf{C}$ is static features, $\mathbf{W}$ is $3DT \times DT$ transformation matrix

### SPG Problem Formulation (Eq. 5.8)
$$\hat{\mathbf{C}} = \arg\max_{\mathbf{C}} p(\mathbf{O}|x, \mathcal{M}) = \arg\max_{\mathbf{C}} p(\mathbf{W}\mathbf{C}|x, \mathcal{M})$$
Subject to: $\mathbf{O} = \mathbf{W}\mathbf{C}$

### SPG Linear System (Eq. 5.15-5.17)
$$\mathbf{R}_x \mathbf{C} = \mathbf{r}_x$$
Where:
$$\mathbf{R}_x = \mathbf{W}^\top \mathbf{\Sigma}_x^{-1} \mathbf{W}$$
$$\mathbf{r}_x = \mathbf{W}^\top \mathbf{\Sigma}_x^{-1} \boldsymbol{\mu}_x$$

### Trajectory HMM Relationship (Eq. 5.19)
$$p(\mathbf{O}|\mathcal{M}) = K_x p(\mathbf{C}|x, \bar{\mathcal{M}})$$
Where: $K_x$ is state-sequence-dependent normalization constant, $\bar{\mathcal{M}}$ is trajectory HMM

### Trajectory HMM Mean (Eq. 5.22)
$$\mathbf{R}_x \bar{\mathbf{C}}_x = \mathbf{r}_x$$
Same linear system as SPG - trajectory HMM mean equals SPG output

### HMM Synthesis Objective (Eq. 5.33)
$$\hat{\mathbf{O}} = \arg\max_{\mathbf{O}} p(\mathbf{O}|\mathcal{W}, \Lambda) = \arg\max_{\mathbf{O}} \sum_{\text{all x}} p(\mathbf{O}, x|\mathcal{W}, \Lambda)$$

## Rules/Algorithms

### MSHMM Training Algorithm (EM-based)
1. Define an initial MSHMM model set M_0
2. Compute optimal state sequence between M_0 and training data O using segmental Viterbi decoder
3. Segment O using the optimal state sequence
4. Re-estimate model parameters based on segmentation to give new model M_1 such that p(O|M_0) <= p(O|M_1)
5. Replace M_0 with M_1 and repeat from step 2
6. Terminate when |p(O|M_n) - p(O|M_{n-1})| < epsilon or max iterations reached

### SPG Algorithm Steps
1. Given HMM M and state sequence x = {x_1, ..., x_T}
2. Construct augmented mean vector mu_x from state means
3. Construct block-diagonal covariance Sigma_x from state covariances
4. Build R_x = W^T * Sigma_x^{-1} * W (banded matrix)
5. Build r_x = W^T * Sigma_x^{-1} * mu_x
6. Solve linear system R_x * C = r_x for smoothed static parameters C

### HMM-based Speech Synthesis Pipeline
1. **Text Analysis**: Convert orthographic text to phonetic segments using pronunciation dictionary
2. **HMM Concatenation**: Build composite HMM Lambda by concatenating CD phone-level HMMs
3. **State Duration**: Determine optimal state durations (typically Gaussian distribution)
4. **Parameter Generation**: Apply SPG algorithm to generate smoothed mel-cepstral and F0 trajectories
5. **Waveform Synthesis**: Pass generated parameters through MLSA vocoder

## Implementation Notes

### For Klatt Synthesis

1. **12 PFS Control Parameters** (from Holmes formant synthesizer):
   - These are the parameters used in the intermediate layer for speech synthesis experiments
   - Include formant frequencies and amplitudes suitable for direct Klatt parameter mapping

2. **Linear Trajectory Model for Coarticulation**:
   - Midpoint + slope parameterization offers a simple way to model formant transitions
   - f_j(t) = (t - midpoint) * slope + center_value
   - Can be applied to any Klatt parameter track

3. **SPG Smoothing for Parameter Trajectories**:
   - Key insight: Smooth trajectories emerge from enforcing consistency between static values and their derivatives
   - Could be applied to Klatt parameter tracks post-generation
   - Requires: static parameters, delta coefficients, covariance information

4. **Processing Steps for Non-linear Trajectory Generation**:
   - Compute delta and delta-delta features for each parameter track
   - Build augmented observation vector O = [c, Delta-c, Delta^2-c]
   - Construct W matrix relating O to static features C
   - Solve linear system R_x * C = r_x for smoothed trajectory

5. **Duration Modeling**:
   - State duration distributions can be Gaussian rather than geometric
   - Allows more natural phone duration variation
   - State duration vector dimensionality equals number of HMM states

### Data Structures

```
MSHMM State:
  - midpoint_vector: float[D]  # D-dimensional intermediate space
  - slope_vector: float[D]
  - covariance: float[D x D]   # Or diagonal for efficiency
  - phone_class: int           # Index into K mapping matrices
  - duration_distribution: Gaussian(mean, variance)

FormantToAcousticMapping:
  - W_k: float[N x M]          # N = acoustic dim, M = formant dim
  - phone_class: int

SPG_Context:
  - W: float[3DT x DT]         # Static-to-augmented mapping
  - mu_x: float[3DT]           # Augmented mean vector
  - Sigma_x: float[3DT x 3DT]  # Block diagonal covariance
  - R_x: float[DT x DT]        # Banded matrix for efficient solving
  - r_x: float[DT]             # RHS of linear system
```

### Edge Cases

- **Boundary handling for delta coefficients**: Replicate first/last feature vector Theta times at boundaries
- **tau_max selection**: Must be large enough to accommodate all phone durations in corpus
- **Numerical stability**: Use SVD for pseudo-inverse computation in W_k estimation
- **Covariance regularization**: May need to add small diagonal for numerical stability

### Dependencies

- Linear algebra library for matrix operations (SVD, matrix inversion)
- Banded matrix solver for efficient SPG computation
- HTK-format file I/O for HMM parameters
- MLSA vocoder for waveform synthesis from mel-cepstral coefficients
