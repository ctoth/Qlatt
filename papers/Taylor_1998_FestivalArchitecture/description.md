Describes the Festival speech synthesis system's core formalism, in which linguistic items are feature structures indexed by positional nodes belonging to arbitrarily many relations that may be lists, trees, or general graphs, all collected into a single utterance object. It argues against string-rewriting architectures such as MITalk and against multi-level stream systems such as Delta and CHATR, showing how intersecting relations remove the "hole" and link-explosion problems, and introduces function features that compute derived values like start time, duration and word accentedness on the fly so no information is duplicated or goes stale. For a formant/source-filter synthesizer it supplies a directly transferable front-end design: store time only on the segment relation, derive all higher-level timing, keep intonation theory choices in run-time string-keyed features, and split a compiled DSP core from a scripted module layer.
