The RaP (Rhythm and Pitch) labeling system is a prosodic annotation framework for spoken English that captures both metrical rhythm and tonal pitch patterns on independent tiers, using relative pitch labels (H, L, E) rather than ToBI's phonological tone categories. The system specifies four annotation tiers (words, rhythm, tones, misc) with detailed conventions for labeling beats/nonbeats, phrase boundaries, starred/unstarred tones, pitch range, false pitch accents, parallelism, and disfluencies. For synthesis, the system provides a principled mapping between metrical structure (beat placement from lexical stress and word class) and F0 contour generation (tone-to-F0 correspondences including peak/valley alignment and monotonic interpolation between targets).
