This paper presents a multivariate acoustic analysis comparing speech from normal, depressed, and high-risk suicidal individuals, using features derived from formants, power spectral density, amplitude modulation, and fundamental frequency. The key contribution is demonstrating that multi-parameter classifiers (particularly using formant frequencies, formant bandwidths, and PSD band ratios) achieve 75-94% classification accuracy, with F0 features surprisingly proving ineffective as discriminators. For speech synthesis, this work provides empirical evidence that psychological states manifest through formant frequency elevation, narrowed higher formant bandwidths, and spectral flattening - suggesting voice quality modeling should prioritize these parameters over F0 when synthesizing affected speech.
