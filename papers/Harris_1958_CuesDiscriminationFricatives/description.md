# Description

Harris (1958) investigates the relative importance of friction noise vs. vocalic (formant transition) portions of fricative-vowel syllables for listener identification. Using a tape-splicing paradigm that recombines friction from one fricative with the vocalic portion of another, the study demonstrates that sibilant fricatives (/s/, /S/) are identified entirely by their noise spectrum, while non-sibilant fricatives (/f/, /theta/) depend primarily on formant transitions in the following vowel. The same pattern holds for voiced counterparts (/z/, /Z/ vs. /v/, /delta/), establishing a fundamental perceptual dichotomy within the fricative class that has implications for synthesis parameter priorities.
