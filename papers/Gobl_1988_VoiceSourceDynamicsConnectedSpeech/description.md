First systematic study of how LF glottal source model parameters (Ee, rg, rk, ra) vary during connected speech, using inverse filtering of Swedish utterances from three adult males and one child. Provides Table III with typical parameter ranges for vowels, consonants, devoicing contexts, and voice onset — directly usable as rules for controlling a dynamic voice source in a formant synthesizer. Demonstrates that most information about pulse shape can be inferred from the negative amplitude of the speech waveform, and that ra and rk systematically covary with Ee across phonetic contexts.
