Lindblom and Sundberg present an articulatory model that derives formant frequencies from four independent articulator parameters: jaw position, tongue body position and shape, lip configuration (rounding/spreading), and larynx height. They systematically vary each parameter while holding others constant, producing detailed formant sensitivity maps that show how F1-F4 respond to each articulator. The paper also introduces the concept of jaw-tongue synergism, explaining "openness" as an optimized jaw position that cooperates with the tongue to produce the desired vocal-tract area function with minimal muscular effort.
